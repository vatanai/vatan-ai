# CLAUDE.md — موتور سئوی هوشمند (Vatan SEO Engine)

> این فایل را **قبل از هر کاری روی این پکیج** بخوان. هدفش این است که در چت‌های بعدی معماری به‌هم نریزد.
> نسخه‌ی فعلی: فایل `VERSION` · تاریخچه: `CHANGELOG.md` · معماری: `ARCHITECTURE.md` · نقشه‌ی راه: `docs/roadmap.md`

## این پکیج چیست؟

یک پکیج لاراول مستقل (`packages/vatan-seo`، فضای نام `Vatan\Seo`) که سئوی تکنیکال و سئوی کلمات کلیدی را تا حد ممکن خودکار و با هوش مصنوعی انجام می‌دهد. فعلاً فقط روی وطن ای‌آی نصب است. بعد از رسیدن به **1.0.0 استیبل**، روی پروژه‌های دیگر (لاراول و وردپرس) تکثیر می‌شود (`docs/launch-new-project.md`).

## قوانین سخت (Non-negotiable)

1. **همه‌چیز داخل پکیج.** کد، ویو، روت، مایگریشن، کانفیگ، پرامپت، پلی‌بوک و CSS/JS فقط در `packages/vatan-seo/`. در پروژه‌ی میزبان فقط این سه نقطه‌ی اتصال مجاز است:
   - ثبت Provider در `bootstrap/providers.php` (+ require بارگذار `bootstrap.php`)
   - یک خط `@include('seo::partials.sidebar')` در سایدبار میزبان
   - مقادیر `.env` با پیشوند `SEO_`
2. **وابستگی به میزبان فقط از `config/seo-engine.php` → `host`.** هیچ کلاس `App\...` را مستقیم در `src/` صدا نزن؛ نام مدل/فیلد/لایوت را از کانفیگ بخوان.
3. **جداول فقط با پیشوند `seo_`** و مایگریشن‌ها ایدمپوتنت (`hasTable`). هیچ‌وقت مایگریشن قبلی را ویرایش نکن؛ مایگریشن جدید بساز.
4. **UI فقط با توکن‌های سیستم طراحی میزبان** (`var(--...)`). هیچ رنگ hex در ویو یا CSS. توکن جدید = تأیید کاربر. کلاس‌ها با پیشوند `seo-`. فونت از میزبان (YekanBakh). متن بخش‌های ناتمام فقط «بزودی».
5. **هر عنوان/آیتم مهم راهنمای کلیکی دارد:** `@include('seo::partials.help', ['k' => '...'])` و متن در `config/help.php` (نه در ویو).
6. **همه‌ی تماس‌های AI فقط از `Vatan\Seo\Ai\Ai`** (نقش ← مدل، سقف بودجه، ثبت هزینه). هیچ‌وقت مستقیم Http به OpenRouter نزن. مدل را هاردکد نکن؛ نقش بده (`fast|strategist|writer|research`).
7. **پرامپت‌ها در `prompts/*.md` با `<!-- version: N -->`.** تغییر معنایی = افزایش نسخه + ثبت در CHANGELOG.
8. **تسک‌ها از پلی‌بوک می‌آیند** (`playbook/*.php`). کلید (`key`) تسک‌ها هرگز عوض نشود. تسک جدید = افزودن به پلی‌بوک + اجرای `php artisan seo:install` (ایدمپوتنت).
9. **برنامه‌ی ۹۰ روزه از `playbook/roadmap.php` می‌آید** (هفته/روز هر تسک، آیین‌های هفتگی، روزانه‌ها، نقطه‌های عطف). تسک جدید پلی‌بوک = حتماً در `assign` هفته و روز بگیرد. هفته‌ها از شنبه‌ی `started_on` شمرده می‌شوند. بعد از تغییر: `php artisan seo:plan --reschedule`.
10. **دو نوع کار:** تسک (یک‌باره یا دوره‌ای انسانی، در «برنامه‌ی کار») و سناریو (تکراری کاملاً خودکار، بدون تأیید، در «سناریوها»). کار تکراری خودکار جدید = هندلر در `src/Scenarios/` + ثبت در `playbook/scenarios.php`.
11. **انتشار محتوا همیشه با تأیید انسان** (پنل یا دکمه‌ی تلگرام). هیچ ایجنتی بدون تأیید روی سایت چیزی منتشر یا تغییر نمی‌دهد.
12. **نسخه‌گذاری:** هر تغییر پکیج → `VERSION` (SemVer) و `CHANGELOG.md`. هر تغییر روی پنل ادمین وطن → ورژن داشبورد هم (`php artisan admin:bump-version`).
13. **تست قبل از تحویل:** `tests/Feature/SeoEngineTest.php` (در `docs/testing.md`) باید سبز باشد.
14. بدون تأیید صریح کاربر: دیپلوی، push، پیام عمومی، تیک زدن تسک‌های چت.

## نقشه‌ی سریع فایل‌ها

| مسیر | چیست |
|---|---|
| `config/seo-engine.php` | آداپتور میزبان، مدل‌های AI، منابع داده، تلگرام |
| `config/budget-tiers.php` | **فایل جامع بودجه**: مبلغ ← پروفایل (مدل‌ها، سقف‌ها، تناوب‌ها) |
| `config/help.php` | همه‌ی متن‌های راهنمای کلیکی |
| `playbook/` | کاتالوگ استاندارد تسک‌ها و سناریوها |
| `prompts/` | پرامپت‌های نسخه‌دار ایجنت‌ها |
| `skills/` | اسکیل‌های سئوی کلاد از گیت‌هاب (مرجع دانش) — `skills/SOURCES.md` |
| `src/Ai` | OpenRouter، مسیریاب مدل، گارد بودجه |
| `src/Data` | سرچ کنسول، PageSpeed، Autocomplete، رتبه (GSC/DataForSEO) |
| `src/Agents` | کشف کلمه، خوشه‌بندی، نویسنده، ناشر، تحلیل‌ها، مشاور |
| `src/Checks` | بررسی‌های خودکار پلی‌بوک (بدون هزینه‌ی AI) |
| `src/Scenarios` | هندلر سناریوهای زمان‌بندی‌شده |
| `src/Connectors` | اتصال به سایت (لاراول همین پروژه / وردپرس) |
| `src/Telegram` | بات @seovatanai_bot |
| `resources/views` | ویوهای پنل (`seo::`) |
| `docs/` | پروپوزال، نقشه‌ی راه، برنامه‌ی ۹۰ روزه (`plan-90.md`)، فعال‌سازی (`activation.md`)، لانچ، تست |
| `src/Services/RoadmapPlanner.php` | سازنده‌ی برنامه‌ی ۹۰ روزه و موج کلمات |
| `src/Agents/Strategist.php` | استراتژیست هفتگی |
