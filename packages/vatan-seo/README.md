# Vatan SEO Engine — موتور سئوی هوشمند

سئوی تکنیکال و کلمات کلیدی، خودکار و با هوش مصنوعی، داخل داشبورد لاراول.

## قابلیت‌ها (نسخه‌ی 0.2.0)

- **برنامه‌ی ۹۰ روزه:** تقویم ۱۳ هفته‌ای با تم هفتگی، تسک روزانه و هفتگی، نقطه‌های عطف ۳۰/۶۰/۹۰ و استراتژیست هفتگی هوش مصنوعی (`docs/plan-90.md`)
- **فعال‌سازی AI:** `docs/activation.md`

- **نمای کلی و مانیتورینگ:** کلیک، ایمپرشن، CTR و میانگین رتبه با مقایسه و اسپارک‌لاین، نمودار ترافیک، توزیع رتبه، روند رتبه‌ی کلمات هدف، بودجه، سلامت فنی، هشدارها و کار ایجنت‌ها
- **کلمات کلیدی:** کشف هوشمند از محصولات (AI + پیشنهاد گوگل + سرچ کنسول)، امتیاز فرصت، نیت، خوشه‌بندی، کلمات هدف با رتبه‌ی روزانه و روند ۳۰ روزه، صفحه‌ی جزئیات با نمودار و پیشنهاد بهینه‌سازی
- **برنامه‌ی کار:** ~۵۰ تسک استاندارد در دو ستون زیرساخت و اهداف، زمان‌بندی امروز/هفته/ماه، بررسی و تیک خودکار، ۶ تسک برای هر کلمه‌ی هدف
- **سلامت فنی:** خزنده‌ی داخلی (۱۸ نوع مشکل)، PageSpeed و Core Web Vitals، پایش روزانه، همنوع‌خواری، llms.txt
- **تولید محتوا:** بریف با پژوهش زنده‌ی Grok، نگارش فارسی، ممیزی سئو و کیفیت، تأیید از پنل یا تلگرام، انتشار خودکار + IndexNow
- **۱۳ سناریوی خودکار** با زمان‌بندی قابل ویرایش، لاگ و هزینه‌ی هر اجرا
- **بات تلگرام:** خلاصه‌ی صبحگاهی، گزارش هفتگی، هشدار افت رتبه، تأیید مقاله با یک دکمه
- **پروفایل بودجه:** فقط یک عدد دلار؛ همه‌چیز خودکار تنظیم می‌شود (رایگان / ۲۰ / ۳۰ / ۶۰ دلار)
- **راهنمای کلیکی** کنار همه‌ی عنوان‌ها

## نصب روی وطن (انجام‌شده)

```bash
# ۱. یک بار
php artisan migrate
php artisan seo:install --budget=20
php artisan seo:telegram setup      # بعد از دیپلوی روی دامنه‌ی اصلی
# ۲. زمان‌بند لاراول باید روی سرور فعال باشد (php artisan schedule:run هر دقیقه)
```

پنل: `/admin/seo` — منو: «سئوی هوشمند»

## دستورها

| دستور | کار |
|---|---|
| `php artisan seo:install [--budget=30] [--url=]` | ساخت/همگام‌سازی سایت، تسک‌ها و سناریوها (ایدمپوتنت) |
| `php artisan seo:plan [--reschedule] [--start=Y-m-d]` | ساخت/تکمیل برنامه‌ی ۹۰ روزه تا ۱۳ هفته جلوتر |
| `php artisan seo:ai-test` | تست واقعی OpenRouter و مدل هر نقش (کمتر از ۱ سنت) |
| `php artisan seo:tick` | اجرای سناریوهای سررسیده (خودکار هر ۵ دقیقه) |
| `php artisan seo:run gsc_sync` | اجرای دستی یک سناریو |
| `php artisan seo:telegram setup\|info\|code` | بات تلگرام |

## متغیرهای `.env`

```env
SEO_TELEGRAM_BOT_TOKEN=          # بات @seovatanai_bot
SEO_TELEGRAM_WEBHOOK_SECRET=     # رشته‌ی تصادفی
SEO_GSC_PROPERTY=sc-domain:aivatan.com
SEO_GA4_PROPERTY=
SEO_PAGESPEED_KEY=               # اختیاری
SEO_INDEXNOW_KEY=                # اختیاری (۳۲ کاراکتر hex)
SEO_PUBLISH_STATUS=published     # یا draft
# اختیاری: پل گوگل، DataForSEO، کلید جدای OpenRouter (پیش‌فرض: کلید پروژه)
SEO_GOOGLE_GATEWAY_URL=
SEO_GOOGLE_GATEWAY_SECRET=
SEO_DATAFORSEO_LOGIN=
SEO_DATAFORSEO_PASSWORD=
```
