# پروپوزال و تصمیم‌های تأییدشده (۱۸ مهر ۱۴۰۵)

## هدف
سیستم سئوی تکنیکال + کلمات کلیدی، تا حد ممکن خودکار با هوش مصنوعی، قابل مشاهده در داشبورد وطن، قابل تکثیر روی پروژه‌های دیگر.

## تصمیم‌های کاربر
| موضوع | تصمیم |
|---|---|
| دامنه | وطن + سایت مشتری‌ها؛ **فعلاً فقط وطن** تا نسخه‌ی استیبل، بعد تکثیر |
| پلتفرم مشتری‌ها | بیشتر لاراول، بعضی وردپرس |
| خودکاری | تحلیل/تحقیق/پیش‌نویس/گزارش خودکار؛ انتشار و تغییر سایت با یک کلیک تأیید. **کارهای تکراری = سناریو بدون تأیید**، فقط قابل کنترل و ویرایش |
| داده | شروع رایگان (سرچ کنسول، GA4، PageSpeed، Autocomplete) با امکان ارتقا |
| بودجه‌ی AI | وطن ۲۰$، مشتری تا ۳۰$؛ قابل تنظیم برای هر پروژه با یک فایل جامع (`config/budget-tiers.php`) |
| مدل‌ها | فعلاً OpenRouter (تا حد امکان) |
| بازار | فقط فارسی / گوگل ایران |
| تسک‌های غیرسئویی چک‌لیست قدیمی | خارج از سیستم (CRM) — فقط سئو + گزارش‌دهی |
| اعلان و تأیید | بات تلگرام جدید @seovatanai_bot |
| UI | بسیار ساده و حرفه‌ای؛ راهنمای کلیکی کنار هر عنوان؛ رتبه‌ی زنده‌ی کلمات و روند رشد |
| تسک‌های دوره‌ای | در راستای ۱) زیرساخت ۲) اهداف کلمات کلیدی |
| کشف کلمه | خودکار بر اساس محصولات |

## منابع طراحی
- چک‌لیست‌های قبلی وطن‌وب (۴ فایل اکسل در `01. SEO Base/files`): چک‌لیست سئوی ماه اول (۱۲۵ آیتم) ← ۴۲ تسک زیرساخت استاندارد و تجمیع‌شده؛ چک‌لیست مدیریتی سئو (حلقه‌ی ماهانه) ← تسک‌های دوره‌ای و گزارش‌ها.
- میزفا تولز (الگوی UI ردیاب کلمات: رتبه‌ی فعلی، روند، تغییر، توزیع، رشد/افت) — اتصال API در نقشه‌ی راه.
- اسکیل‌های گیت‌هاب: `skills/SOURCES.md`.

## کمبودهای سیستم قبلی که اضافه شد
تحقیق کلمه‌ی داده‌محور، خوشه‌بندی، نقشه‌ی کلمه ← صفحه، همنوع‌خواری، افت محتوا، فرصت‌های CTR و صفحه‌ی دوم، E-E-A-T، اسکیما، GEO (ربات‌های AI، llms.txt، قابلیت نقل)، INP، IndexNow، پایش سلامت روزانه، هزینه‌ی شفاف AI.
