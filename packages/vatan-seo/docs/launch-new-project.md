# لانچ موتور سئو روی یک پروژه‌ی جدید

> وقتی به کلاد می‌گویید «سیستم سئوی هوشمند را روی پروژه‌ی X با بودجه‌ی ۳۰ دلار لانچ کن»، دقیقاً همین مراحل اجرا می‌شود.
> پیش‌نیاز: موتور به نسخه‌ی 1.0.0 استیبل رسیده باشد (تا آن موقع فقط روی وطن).

## ورودی‌هایی که باید معلوم باشد

| ورودی | مثال | اثر |
|---|---|---|
| آدرس سایت | `https://example.ir` | دامنه، خزش، سرچ کنسول |
| پلتفرم | لاراول / وردپرس | کانکتور انتشار و خواندن محصولات |
| **سقف ماهانه‌ی AI** | `30` | پروفایل از `config/budget-tiers.php` (۳۰ ← حرفه‌ای) |
| معرفی برند | ۳ تا ۵ خط | کیفیت کلمات و مقالات |
| رقبا | ۳ دامنه | تحقیق و مقایسه |
| بات تلگرام | توکن یک بات جدید | هشدار و تأیید |

## مسیر بر اساس مبلغ (خلاصه‌ی `config/budget-tiers.php`)

| مبلغ ماهانه | پروفایل | کلمه‌ی هدف | مقاله/ماه | پژوهش زنده | خزش | منبع رتبه |
|---|---|---|---|---|---|---|
| زیر ۵$ | رایگان | ۲۰ | ۰ (فقط بریف) | ۰ | ۱۵۰ | سرچ کنسول |
| ۵ تا ۲۴$ | پایه | ۲۰ | ۸ | ۲۵ | ۴۰۰ | سرچ کنسول |
| ۲۵ تا ۴۹$ | حرفه‌ای | ۴۰ | ۱۴ | ۶۰ | ۸۰۰ | سرچ کنسول |
| ۵۰$+ | رشد | ۱۰۰ | ۳۰ | ۱۵۰ | ۲۰۰۰ | DataForSEO (در صورت اتصال) |

برای نیاز خاص یک مشتری، بدون تغییر این فایل: `seo_sites.settings.overrides` (مثلاً `{"limits":{"articles_per_month":20}}`).

## الف) پروژه‌ی لاراولی

1. کپی پوشه‌ی `packages/vatan-seo` (یا `composer require vatan/seo-engine` بعد از انتشار خصوصی).
2. `composer.json` میزبان: `"Vatan\\Seo\\": "packages/vatan-seo/src/"` در `autoload.psr-4` ← `composer dump-autoload`.
3. `bootstrap/providers.php`: `require_once base_path('packages/vatan-seo/bootstrap.php');` و `Vatan\Seo\SeoEngineServiceProvider::class`.
4. `config/seo-engine.php` را publish کنید (`php artisan vendor:publish --tag=seo-engine-config`) و بخش `host` را تنظیم کنید: لایوت، پارشیال هدر، کلاس main، گارد ادمین، مدل/فیلدهای محصول و مقاله.
5. اگر داشبورد توکن‌های طراحی وطن را ندارد: `host.fallback_tokens = true`.
6. منو: `@include('seo::partials.sidebar')` (یا لینک ساده به `/admin/seo`).
7. `.env`: متغیرهای `SEO_*` (README).
8. `php artisan migrate && php artisan seo:install --budget=30 --url=https://example.ir`
9. تنظیمات پنل: آپلود سرویس‌اکانت، معرفی برند، رقبا ← `seo:telegram setup` ← کد اتصال مدیر.
10. زمان‌بند لاراول روی سرور فعال باشد.

## ب) سایت وردپرسی مشتری

موتور روی داشبورد وطن (یا داشبورد مرکزی آینده) نصب است و سایت وردپرسی از راه REST API وصل می‌شود:
1. در وردپرس: کاربران ← پروفایل ← Application Passwords ← ساخت رمز.
2. در پنل موتور: تنظیمات ← اتصال به سایت ← وردپرس + آدرس، نام کاربری، رمز برنامه، وضعیت انتشار.
3. محصولات از WooCommerce Store API (یا برگه‌ها) خوانده می‌شوند؛ مقاله‌ها به‌صورت پیش‌نویس/انتشار در وردپرس ثبت می‌شوند.
> نسخه‌ی ۰٫۱ تک‌سایتی است؛ مدیریت چند سایت در یک پنل در نقشه‌ی راه (فاز ۵) است.
