# پرامپت‌های ایجنت‌ها

هر فایل یک پرامپت سیستم است. متغیرها با `{{name}}` جایگزین می‌شوند (کلاس `Vatan\Seo\Support\Prompt`).
قانون: هر تغییر معنایی در یک پرامپت → شماره‌ی `version` بالای فایل یک واحد زیاد شود و در CHANGELOG پکیج ثبت شود.
منبع دانش این پرامپت‌ها: اسکیل‌های `skills/claude-seo`, `skills/claude-blog`, `skills/geo-seo` (نسخه‌ها در `skills/SOURCES.md`).
