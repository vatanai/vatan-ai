# کارخانه‌ی هوشمند محتوای وطن — content-lab

| پوشه | چی بریزی |
|---|---|
| 00-inbox | ویدیوهای مرجع سبک (ویدیو بیسیک). فقط بریز؛ بقیه با کلاده |
| 01-styles | خودکار: هر سبک یک پوشه با ویدیوها، فریم‌ها، style.md و style.json |
| 02-music/audio | فایل‌های صوتی با مجوز (mp3/wav/m4a) |
| 02-music/from-video | ویدیوهایی که موزیکشون تأییده؛ صدا خودکار استخراج می‌شه |
| 03-brand | لوگو، فونت، رنگ، اسکرین‌شات آمار پیج (insights) |
| 04-before-after | عکس خام محصول + خروجی وطن (اسم یکسان: x-before.jpg / x-after.jpg) |
| 05-calendar | خودکار: تقویم محتوا |
| 06-productions | خودکار: هر پست یک پوشه (سناریو، رندرها، کاور، کپشن، استوری‌ها) |
| 07-reports | خودکار: گزارش‌ها |

فایل‌های ویدیو/صوت/عکس وارد git نمی‌شن.
