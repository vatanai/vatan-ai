# قوانین تم روز و شب اپ و سایت وطن

این سند منبع رسمی رنگ پایه صفحه در اپ کاربری و سایت اصلی است. مقدار اجرایی این قوانین در `public/css/theme-tokens.css` نگه‌داری می‌شود.

| کاربرد | حالت شب | حالت روز |
|---|---|---|
| پس‌زمینه اصلی صفحه (`--vatan-bg-page`) | `#000000` | `#ffffff` |
| متن پایه صفحه (`--vatan-text-page`) | `#ffffff` | `#0c0c10` |
| پس‌زمینه هدر مشترک (`--vatan-header-bg`) | `#000000` | `#000000` |

## قوانین

1. تمام صفحات اپ، سایت اصلی و فوتر مشترک باید رنگ پس‌زمینه پایه را از `var(--vatan-bg-page)` بخوانند.
2. مقدار پس‌زمینه پایه نباید داخل فایل هر صفحه دوباره تعریف شود.
3. تغییر تم با کلاس `light` روی عنصر `html` انجام می‌شود.
4. تغییر این مقادیر فقط با درخواست صریح کاربر مجاز است.
5. هدر مشترک اپ و سایت در تمام صفحات، اندازه‌ها و حالت‌های روز و شب همیشه از `var(--vatan-header-bg)` استفاده می‌کند.
6. رنگ سطوح داخلی مانند کارت و پنل مستقل از رنگ پایه صفحه است و از توکن‌های مخصوص خودش استفاده می‌کند.
