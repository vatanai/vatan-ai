# Layout دسکتاپ

در نسخه Desktop صفحه به دو ستون تقسیم شود.

## ستون چپ (حدود 60%)

بخش گالری تصاویر

این قسمت همیشه Sticky باشد.

شامل:

* تصویر اصلی بزرگ
* نمایش با کیفیت بالا
* نسبت تصویر ثابت
* دارای Hover مناسب
* قابلیت تغییر تصویر بدون Reload صفحه

در پایین تصویر اصلی، Thumbnailها نمایش داده شوند.

اولین Thumbnail همیشه:

**عکس قبل**

باشد.

این آیتم مستقل از سایر تصاویر است.

زیر آن نوشته شود:

عکس قبل

سپس تصاویر خروجی محصول نمایش داده شوند.

اگر محصول دارای چندین تصویر باشد:

* با کلیک روی هر Thumbnail
* همان تصویر در بخش بزرگ سمت چپ نمایش داده شود.
* بدون Refresh صفحه
* با Transition نرم

## ستون راست (حدود 40%)

اطلاعات محصول

به ترتیب:

* نام محصول
* توضیح کوتاه
* دسته‌بندی
* تعداد ساخت (در صورت وجود)
* قیمت
* دکمه ساخت محصول

در ادامه:

اگر محصول دارای تنظیمات (Variables) باشد:

تمام فیلدها نمایش داده شوند.

مانند:

* Select
* Radio
* Checkbox
* Text
* Number
* Switch
* Color
* Image Upload

تمام این فیلدها به صورت داینامیک از دیتابیس ساخته شوند.

در انتها:

دکمه بزرگ

«شروع ساخت»

نمایش داده شود.

این CTA همیشه واضح و قابل مشاهده باشد.
